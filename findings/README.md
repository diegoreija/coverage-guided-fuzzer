# Findings

This directory is where real findings from running this engine against actual software (not the toy example target) get documented — one file per finding, with:

- The target (name, version, where to get it)
- The exact command used to reproduce the campaign
- The triggering input
- Root cause analysis
- Whether it was reported upstream, and the response if any

No entries yet — the toy target in `targets/toy_ftp_parser.py` exists to validate the engine works correctly (see `examples/sample_campaign_run.md`). Findings against real targets belong here once they exist.
